# FireDoor Nation Inspections — Live Deployment

This public repository contains only the compiled static deployment for the
FireDoor Nation inspection PWA. The private application source, backend
credentials, migrations, and development history are not included here.

Production source repository: private FireDoor Nation repository.

## Deployment

GitHub Pages serves the `main` branch from the repository root. Future releases
are produced from the private source repository with the base path
`/firedoor-nation-inspections-live/`, then the generated `dist` contents are
published here.
